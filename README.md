# SQL Analytics – 50 Problems

This repository documents my journey of solving 50 SQL analytics problems using the Northwind and Chinook sample databases.

The project progresses from basic SQL queries to advanced analytics involving joins, aggregations, window functions, and Common Table Expressions (CTEs).

## Objectives

- Practice SQL using real-world datasets
- Improve analytical thinking
- Build a portfolio-ready SQL repository
- Learn production-style SQL writing

## Concepts Covered

- SELECT
- WHERE
- ORDER BY
- LIMIT
- JOINs
- GROUP BY
- HAVING
- Aggregate Functions
- Window Functions
- CTEs
